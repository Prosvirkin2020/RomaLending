# Сайт-визитка — Просвиркин Роман

Структура:
- `index.html` — разметка
- `css/style.css` — стили (адаптив внизу файла)
- `js/script.js` — копирование контактов и активная вкладка меню

Как выложить на GitHub Pages:
1. Создать репозиторий `Prosvirkin2020.github.io`.
2. Загрузить в него эти файлы (index.html в корне).
3. Через пару минут сайт откроется по адресу https://prosvirkin2020.github.io
